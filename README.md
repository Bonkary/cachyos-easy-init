# cachyos-init-install
Just a script to install and setup some basic things in CachyOS for my buddy

This script uses and will install the following 3rd party packages:
    xterm

PLANS:
    System update
    Install basic apps (discord, steam, etc)
    Package manager
    Useful packages/deps
    Winboat
    'Gaming Packages'
    Drivers

    ## SECURE BOOT ##
    Ask if Dual Boot
    CUDA or AMD
    SKip wallpaper
    
    ## HERMES ##
    kms or evdi
    multi output
