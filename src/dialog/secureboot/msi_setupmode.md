### MSI Motherboards
*Note: Kinda unsure on MSI boards. If you see it, do it. Nothing will break. There's a photo on the wiki, it's just too ugly for me to place it in a creation of mine.*

1. If your motherboard has an EZ Mode and Advanced Mode, you'll need to switch to <u>Advanced Mode</u>. Look around the screen and somewhere it'll tell you how.
2. There should be a tab called <u>Boot</u>. Go there.
3. Go to the <u>Secure Boot</u> section.
4. Set <u>Secure Boot</u> to <u>Custom</u>
5. Select <u>Maximum Security</u> compatability option.
6. Go to <u>Key Management</u>
7. Select <u>Enroll all Factory Default Keys</u> and select <u>Disabled</u>.<br>
8. Select <u>Delete all Secure Boot Variables</u> and if there's another prompt, select the one that deletes them.
